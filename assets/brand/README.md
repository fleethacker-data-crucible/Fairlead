# Fairlead brand


| File | What it is |
|---|---|
| `emblem-light.png`, `emblem-dark.png` | Full emblem (Fleet frame and wordmark), 1024 px, on the Chart room (ivory) and Night watch (navy) backgrounds. The detailed originals: raster artwork, not generated by any script |
| `web/public/brand/emblem-*.png` | The in-app copies: 512 px (the app draws the emblem at up to 280 px), backdrop made transparent (flood fill from the corners at 1.5% tolerance) |
| `mark.svg` | Icon-only mark, simplified to read at 32 px: a roller fairlead with the line led between its rollers |
| `mark-256.png`, `mark-64.png` | The mark as PNG |
| `favicon.ico` | Browser icon (16, 32, 48, 256) |
| `tray.ico` | Tray icon fallback (16 to 256 px): Fairlead's tile from the FleetHacker tray kit (`module/Fairlead/vendor/fleet-tray`, `Export-FleetTrayIco`), used where `Add-Type` is blocked. Normally the tray draws it at the tray's size |

The emblem is an engraved illustration in the Scrimshaw style: a brass roller fairlead bolted to a ship's rail, a
hemp line led cleanly between its rollers and out of the circle on both sides, breaking waves below, the brass
compass star above, and a starboard running light glowing green on the rail (the signature accent, `#a3d65c` night,
`#4d7a1a` chart room). Everything follows `docs/UNIFIED-UI.md` section 8.

Regenerate the mark and icons with `powershell -File build\New-FairleadBrand.ps1` (needs Edge or Chrome on the build
machine). It leaves the emblems alone.

All four emblem PNGs are palette-compressed with `pngquant --quality=75-95` (about 0.5 MB per master, 0.12 MB per in-app copy).
